                    Given an integer <code class="code-font bg-slate-900 px-1.5 py-0.5 rounded text-xs text-blue-300">n</code>, return an array of length <code class="code-font text-xs text-slate-400">n + 1</code> such that for each <code class="code-font text-xs text-blue-300">i</code>, the value is the number of <strong>1's</strong> in the binary representation of <code class="code-font text-xs text-blue-300">i</code>.

<div>

<span class="text-slate-200 text-sm font-bold block">Right Shift (<code class="code-font text-blue-300">i &gt;&gt; 1</code>)</span>

<p class="text-slate-400 text-xs leading-snug">

                            This is equivalent to <code class="code-font text-xs">i / 2</code>. We already know the bit count for this smaller number.

                        </p>

</div>

</div>

<div class="flex items-start gap-3">

<div class="bg-amber-500/20 p-1.5 rounded text-amber-400 mt-0.5">

<i class="fa-solid fa-1 text-xs"></i>

</div>

<div>

<span class="text-slate-200 text-sm font-bold block">LSB Check (<code class="code-font text-amber-300">i &amp; 1</code>)</span>

<p class="text-slate-400 text-xs leading-snug">

                            If <code class="code-font text-xs">i</code> is odd, it has one more '1' bit (at the end) than <code class="code-font text-xs">i / 2</code>.

                        </p>

</div>

</div>
